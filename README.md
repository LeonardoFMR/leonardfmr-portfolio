## Run Locally

No additional dependencies or installation steps are required.

1. Clone the repository: `git clone https://github.com/LeonardoFMR/leonardfmr-portfolio.git`
2. Open the project folder: `cd leonardfmr-portfolio`
3. Open `index.html` in your browser or use Live Server in Visual Studio Code.
